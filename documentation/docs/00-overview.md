# 00 — Project overview and terminology

## Purpose

The project turns a technical content repository into a developer portfolio and engineering library. An individual article is AsciiDoc, the site generator is Antora, and the custom UI controls the look and behavior of the output HTML.

**Use cases:** publish Java and low-level design (LLD) tutorials, high-level design (HLD) case studies, distributed-systems notes, a résumé/contact page, and navigable documentation.

## What each piece does

| Item | Role | Edited for what? |
|---|---|---|
| `antora-playbook.yaml` | Site orchestration | Site title, landing page, content Git sources, UI ZIP, output dir, header-link source |
| `antora.yml` | Component version descriptor | Component name, version, and registered navigation files |
| `modules/<module>/pages/*.adoc` | Publishable articles | Your actual writing and links |
| `modules/ROOT/nav-generated.adoc` | Generated navigation input | Normally **do not hand-edit**; generated by Python |
| `modules/ROOT/nav.adoc` | Optional manual navigation | Custom nesting and order |
| `tools/generate_nav.py` | Optional content scanner | Generate grouped links for the sidebar |
| `ui/*.zip` | Complete UI bundle | Styles and rendering for every generated page |
| `layouts/default.hbs` | Article layout | Documentation pages, sidebar, body, TOC |
| `layouts/portfolio.hbs` | Optional hero résumé layout | Special landing page |
| `partials/nav-tree.hbs` | Navigation HTML | Sidebar links and expandable groups |
| `js/site.js` | Browser interactions | Dropdown state, filter, mobile sidebar, header link URL handling, TOC |
| `css/site.css` | Docs theme | Header, sidebar, article, TOC and responsiveness |
| `css/portfolio.css` | Résumé theme | Optional portfolio homepage |

## Important terms

- **Site:** The entire Antora build. Can include many components and versions.
- **Component:** Logical documentation product or collection, identified by `name` in `antora.yml` (example: `gareeb-engineer`).
- **Version:** Version label for a component. Example: `v1.0`; for unversioned content use `~`.
- **Module:** Content area such as `ROOT`, `java`, `lld`, `hld`.
- **Page resource ID:** An Antora logical reference, for example `v1.0@gareeb-engineer:java:index.adoc`.
- **Site start page:** Article shown after the site's `/index.html` redirect; configured under `site.start_page`.
- **Navigation file:** AsciiDoc list of links registered in `antora.yml`.
- **UI bundle:** A ZIP with templates, CSS and JavaScript. It does not contain your live article text.
- **Generated output:** HTML/CSS/JS produced by `antora`, commonly in `build/site` or your configured `build-output`.

## Key rules

Creating `.adoc` publishes a page when the file is in an included content source, **but doesn't make it appear in the sidebar unless a registered navigation file links to it**. The Python generator is our optional convenience layer, not built-in Antora automation.

Custom layout means HTML/CSS can change while your AsciiDoc syntax stays standard. Some browser-side conveniences require custom scripts; they are not part of AsciiDoc conversion.
