== Evolution of Modern Memory Management

Java manages memory automatically with a garbage collector. The details depend on the selected collector and workload.

=== Generational Hypothesis

Many Java collectors organize work around object lifetimes and allocation behavior.

== Choices of GC

* Serial GC
* Parallel GC
* G1 GC
* ZGC

== Code block features

A plain source block gets the dark theme, a language label, Copy and Open buttons,
line numbers and syntax colours automatically:

[source,java]
----
public final class Allocation {

    private final String region;

    public Allocation(String region) {
        this.region = region;
    }

    public String describe() {
        return String.format("allocated in %s", region);
    }
}
----

Add `highlight=` to draw attention to specific lines. Quote the value when it
contains a comma:

[source,java,highlight="3,7..9"]
----
public final class Eden {

    private int surviving;          // highlighted

    void collect(int[] objects) {
        for (int age : objects) {
            if (age > TENURING_THRESHOLD) {   // highlighted
                surviving++;                  // highlighted
            }                                 // highlighted
        }
    }
}
----

Use `role=no-linenums` when line numbers add noise:

[source,bash,role=no-linenums]
----
java -XX:+UseG1GC -Xms512m -Xmx512m -jar app.jar
----
