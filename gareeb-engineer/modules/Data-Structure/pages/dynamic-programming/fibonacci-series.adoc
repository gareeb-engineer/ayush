== Question

[.cp-box.cp-question]
--
Given an integer `N`, print the first N numbers of the Fibonacci series.
The Fibonacci series is defined as:

* `F(0) = 0`
* `F(1) = 1`
* `F(n) = F(n-1) + F(n-2)` for `n > 1`
--

== Approach to Solve

[.cp-box.cp-approach]
--
We can solve this problem using multiple approaches:

* *Naive Recursion* -- simple but has exponential time complexity (`+O(2^N)+`).
* *Memoization (Top-Down DP)* -- stores previously computed values to avoid redundant work (`O(N)`).
* *Tabulation (Bottom-Up DP)* -- builds the solution iteratively (`O(N)`).
* *Space Optimized* -- keeps only the last two values (`O(1)` space).
--

== Java Implementation

.Show Code (Java Solution)
[%collapsible]
====
[source,java]
----
import java.util.Scanner;

public class FibonacciSeries {

    // Space optimised bottom-up DP: only the previous two values are kept.
    static long[] series(int n) {
        long[] out = new long[Math.max(n, 0)];
        long prev = 0, curr = 1;
        for (int i = 0; i < n; i++) {
            out[i] = prev;
            long next = prev + curr;
            prev = curr;
            curr = next;
        }
        return out;
    }

    // Top-down DP for a single term, memoised so each subproblem is solved once.
    static long term(int n, long[] memo) {
        if (n < 2) return n;
        if (memo[n] != -1) return memo[n];
        return memo[n] = term(n - 1, memo) + term(n - 2, memo);
    }

    public static void main(String[] args) {
        Scanner in = new Scanner(System.in);
        int n = in.nextInt();

        StringBuilder sb = new StringBuilder();
        for (long value : series(n)) {
            sb.append(value).append(' ');
        }
        System.out.println(sb.toString().trim());

        long[] memo = new long[Math.max(n, 2)];
        java.util.Arrays.fill(memo, -1);
        System.out.println("F(" + n + ") = " + term(n, memo));
    }
}
----
====

== Complexity Analysis

[.cp-box.cp-complexity]
--
* *Time Complexity*: `O(N)`
* *Space Complexity*: `O(1)` (for the optimised approach)
* *Recursive approach*: `+O(2^N)+` time, `O(N)` space (recursion stack)
--
